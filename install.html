JARVIS · Chrome extension

Install Jarvis

For your Motorola and Chrome Beta setup, the easiest method is to use Jarvis as a phone web app instead of an extension. Android browsers do not support unpacked extensions the way desktop Chrome does.

Open the app in your browser, then tap the menu and choose Add to Home screen or Install app. This gives you a cleaner phone-friendly install path.

Open Jarvis on your phone

This is the simpler option for your phone. It works in Chrome Beta and gives you a quick launcher without the desktop extension workflow. If your browser only offers Create shortcut, that is the Android fallback and still works as a home-screen app.

If you still want the desktop extension version, download the package, extract it, and load its folder in Chrome. This setup takes a few minutes and is for a computer.

Chrome requires this one-time unpacked-extension step for downloads outside the Chrome Web Store. Keep the extracted folder where it is; Chrome loads the extension from that folder.

Install steps

  1. Open the mobile app page in Chrome Beta on your Motorola. This is the recommended path for your phone.
  2. Try the menu in Chrome Beta and choose Add to Home screen or Install app. If your browser only offers Create shortcut, select that — it is the normal Android fallback.
  3. Open the new app shortcut from your home screen. It runs Jarvis as a browser-based app and keeps the orb interface working on your phone.
  4. If you want the desktop extension, open chrome://extensions on a computer, enable Developer mode, and select Load unpacked.
  5. Choose the extracted folder with manifest.json in it. Use the extracted jarvis-extension folder, not the ZIP file itself.
